# Project Operating Rules

This repository is the source of truth.

Do not rely on old chat history for project state.

Always inspect:
- docs/product.md
- docs/architecture.md
- agent/current-task
- agent/tasks/<current-task>/
- relevant specs/
- git status / git log / actual code

Persistent decisions belong in the repository, not only in chat.

Agent roles live under agent/roles/.

If the current task is unclear, do not invent requirements.
Escalate to the Product agent.
